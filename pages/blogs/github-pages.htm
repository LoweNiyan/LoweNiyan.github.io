搭建 GitHub Pages

2026年7月8日   22:30
网站采用纯静态方案：无构建工具，无框架，无包管理器。所有页面使用 .htm 扩展名，jQuery 3.6.3 来自 ASP.NET CDN。

页面结构：
- index.htm — 首页，Hello World 视差效果 + more 面板
- pages/about.htm — 关于页（待填充）
- pages/log_index.htm — 动态/日志页
- pages/connect.htm — 联系页
- pages/blogs/ — 博客文章目录

字体方案从 Green Screen 替换为 Good Old DOS（DOS 终端风格），正文从 Rubik 迁移到浏览器默认衬线体，整体更文艺。
